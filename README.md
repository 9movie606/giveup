## **实测数据：纯三网CMIN2系列到底稳不稳**

**回程路由（traceroute验证）**

三网回程全部强制走CMIN2，路径高度一致——从洛杉矶出发，经AS58807（中国移动国际）到上海入口（AS9808），再转国内各省市。以上海电信为例：


洛杉矶 → 223.120.201.48 (AS58807, 移动) → 223.120.197.5 (AS58807, 移动) 
→ 223.120.161.5 (AS58807, 上海, 移动) → 221.183.92.117 (AS9808, 上海, 移动) 
→ 202.97.60.217 (AS4134, 上海, 电信) → 目的地


上海联通、北京电信、深圳移动等节点的回程路径也都遵循同样的模式：**洛杉矶→移动国际骨干→上海移动入口→转国内对应运营商**。全程不走公共对等节点，这就是CMIN2回程稳定的核心原因。

**延迟表现**

国内三网主要节点延迟大致在126-165毫秒之间，上海方向最低约126毫秒，北京/深圳方向约150-165毫秒。这个延迟水平在美西VPS里属于第一梯队，晚高峰波动也不大。

**带宽与下载速度**

广州联通家宽浏览器直连下载，非高峰期能跑到接近带宽上限；晚高峰有所下降但依然可用。广东江门移动晚高峰下载速度表现稳定，CMIN2对移动用户的加成非常明显。湖北十堰电信（100M带宽）和四川眉山联通晚高峰也都能跑出不错的速度。

**流媒体解锁**

这台机器分配的是美国原生IP，流媒体解锁能力相当强——TikTok、Netflix、Disney+、YouTube Premium等跨区域和北美流媒体基本都能解锁，不用额外折腾。
